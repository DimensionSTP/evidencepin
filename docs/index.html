EvidencePin 개인정보 처리 안내

적용 대상: 확장 프로그램 0.1.0. 작성일: 2026-11-13.

브라우저에서 처리하는 정보

사용자가 선택한 문장의 저장 메뉴를 실행하면 문장, 페이지 URL, 제목, 저장 시각, 기록 식별자와 문장의 SHA-256 지문을 브라우저 로컬 저장소에 보관합니다. URL이나 선택 문장에 개인정보가 포함되어 있으면 그 내용도 함께 보관됩니다. 저장 실패 시에는 실패 이유도 로컬에 기록합니다.

사용자가 원문 재검사를 누르면 현재 탭의 URL과 페이지 본문 앞 100만 자를 브라우저 안에서 읽어 저장한 문장과 비교합니다. 재검사용 본문 전체는 기록으로 저장하지 않습니다. 백그라운드에서 방문 기록이나 페이지 전체를 수집하지 않습니다.

이용 목적과 외부 전송

정보는 사용자가 요청한 인용 보관, 목록 표시, 원문 재검사와 파일 내보내기에만 사용합니다. 확장 프로그램은 기록을 개발자나 제삼자의 서버로 전송하지 않습니다. 광고·분석 추적·원격 코드·AI 모델 API·클라우드 동기화가 없습니다. 개발자는 확장 프로그램을 통해 로컬 기록에 접근하지 않습니다. 이 이용 범위는 Chrome Web Store 사용자 데이터 정책의 제한된 사용 요건을 따릅니다.

원문 열기는 사용자의 브라우저에서 해당 웹사이트를 방문하는 동작이며, 방문한 사이트에는 그 사이트의 정책이 적용됩니다. JSON 내보내기와 Markdown 내보내기는 사용자가 지정한 로컬 다운로드 위치에 파일을 생성합니다. 사용자가 파일을 공유하는 경우 공유 범위는 사용자가 결정합니다.

보관과 삭제

기록은 사용자가 삭제하거나 브라우저 프로필의 해당 확장 저장소가 삭제될 때까지 보관합니다. 팝업에서 개별 삭제 또는 전체 삭제를 실행할 수 있습니다. 확장 프로그램 제거 시 브라우저의 해당 확장 저장소가 삭제됩니다. 다운로드한 파일은 별도 파일이므로 사용자가 직접 삭제해야 합니다.

브라우저 로컬 저장소와 내보낸 파일에 별도 앱 암호화를 적용하지 않습니다. 같은 기기와 브라우저 프로필에 접근할 수 있는 사람으로부터 데이터를 보호하는 별도 잠금 기능은 없습니다. 서버 백업과 가져오기 기능도 없습니다.

권한 사용

  • contextMenus: 선택 문장을 저장하는 우클릭 메뉴를 표시합니다.
  • storage: 인용 기록과 저장 오류를 브라우저 로컬에 보관합니다.
  • activeTab: 사용자가 실행한 확장의 현재 탭 접근을 이용해 URL과 출처를 확인합니다.
  • scripting: 사용자가 재검사를 누를 때 현재 페이지 본문을 읽습니다.

계정·결제·연락처·위치 권한을 요청하지 않습니다. 지원 문의를 보낼 때에는 실제 인용 기록이나 개인정보 대신 합성 예시로 문제를 설명할 수 있습니다. 공개 스토어 배포 시 문의 경로는 스토어에 표시되는 개발자 지원 경로를 사용합니다.
